1. Executive Summary

Project Overview & Core Mission

🛒

The Problem

Traditional platforms suffer from stock discrepancies during high-concurrency checkouts, leading to overselling, race conditions, and heavy manual decrement burdens on admins.

⚡

The StockPulse Solution

Reactive customer-driven inventory architecture where customer checkouts atomically decrement stock, automatically recalculate stock statuses, and alert admins for physical refills.

🛡️

Key Pillars

Dual-Role Authentication, Dedicated Refill Center, Multi-Product Shopping Cart, Self-Service Order Cancellation with Restock, and Zero-API local simulation.

2. Technology Architecture

Full-Stack Technologies Breakdown

⚡ Backend & API Framework

  • Node.js (v18+): Asynchronous, event-driven runtime.
  • Express.js: High-throughput REST API gateway with robust routing.
  • TypeScript (Strict Mode): Powers 53,000+ LOC ensuring strict type safety.
  • Domain-Driven Design (DDD): Decoupled Controllers, Services, and DTOs.

🗄️ Database & Persistence

  • Prisma ORM: Declarative schema modeling and auto-generated query clients.
  • 18 Relational Models: Users, Customers, Products, Variants, Inventory, Orders.
  • ACID Transactions: Atomic locking via $transaction.
  • Audit Ledger: Immutable transaction logging for restocks and orders.

🎨 Frontend & UI Layer

  • React 18 & Vite: Component-based SPA architecture with custom state hooks.
  • Tailwind CSS (v3): Responsive utility classes with modern dark glassmorphism.
  • Unified ES6+ Web Engine: start_servers.js serving instant live portals.
  • Lucide Icons: Crisp vector iconography.

🐳 DevOps & Testing Suite

  • Docker & Docker Compose: Multi-container deployment definition.
  • Turborepo & NPM Workspaces: Monorepo build pipeline orchestration.
  • Git Version Control: 6 Non-Fast-Forward PR Merges and semantic commit log.
  • 26 Automated Test Suites: Covering concurrency, RBAC, and inventory.
3. Special Feature Highlight

🚨 Dedicated Out-of-Stock Refill Center

🚨

Out of Stock Refill Center Card

Automated Alert Queue

The Admin Portal features an emergency Refill Card that exclusively filters items with 0 available units. Beside each item is a "⚡ Refill Stock" button. Clicking it prompts the admin for the refill quantity count and audit reason, instantly changing status to ACTIVE and immediately unlocking the product for customer purchase!
